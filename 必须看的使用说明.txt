1. 这个程序是做什么的
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
电脑感觉不对劲（突然重启、游戏卡一下、网页打不开、软件一打开就闪退、
开机特别慢）时，双击「双击运行体检.exe」，点最大的那个按钮，一般几秒钟。
它会给出三种颜色：

  ● 红 = 需处理：这一项建议尽快照下面的步骤做
  ▲ 黄 = 建议留意：不用急着动手，先观察几天
  ○ 绿 = 正常：这一项查过了，没问题
  － 灰 = 未获取：这台机器上看不到这一项（比如台式机没有电池），
                     看不到不等于有问题

界面里不会出现英文代码和内部名词。你看到的每一句话都是给人看的。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 它绝对不做的四件事（可以放心）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 不联网：程序里没有网络功能，断网也能完整使用，也不会上传任何东西。
  · 不改设置：不改注册表、不删文件、不结束任何进程、不动杀毒软件的
    设置和白名单。
  · 不自动打开网页：体检结束后不会自己弹浏览器，报告要你点
    「打开报告所在的文件夹」才会打开。
  · 不留垃圾：除了你生成的报告，它不往电脑里写别的。

它只做一件事：读取本机已经存在的信息（系统事件记录、驱动与显卡信息、
启动项、磁盘剩余、电池、桌面图标角标被占了多少、虚拟内存有没有被关、
系统工具有没有被脚本锁住、软件界面资源还剩多少），翻译成一句话告诉你。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. 第一次打开时 Windows 拦你，是正常的
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
因为这是个人开发者做的小工具，没有花钱买数字签名，所以：

  A) 蓝底弹窗「Windows 已保护你的电脑」
     → 点「更多信息」→ 再点「仍要运行」。
     这只出现在第一次。

  B) 杀毒软件（ Windows Defender / 卡巴斯基 / 火绒 ）可能把这个 exe
     报成可疑。原因是"打包成单文件的 Python 程序"这个形态本身像恶意软件，
     不是程序里有什么坏东西。处理顺序：
       1. 先别急着加白名单。用第 4 节的指纹核对文件是不是你下载的那一个。
       2. 如果确实被拦截：Defender 里点「保护历史记录」，找到那条，
          选「操作 → 允许 / 还原」。
       3. 需要长期放行时，请你自己手动添加：
          设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 →
          病毒和威胁防护设置「管理设置」→ 排除项「添加或删除排除项」→
          添加文件夹 → 选择这个程序所在的整个文件夹。
          ※ 本程序不会替你做这一步，也不会自动写这些设置。
       4. 仍然不放心就把整个文件夹删掉，它不会留下任何痕迹。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. 怎么确认你拿到的文件没被人改过
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在发布页会给出这个 exe 的 SHA256 指纹（一行 64 位字符）。核对方法：
右键 exe → 属性 → 详细信息（或让帮你的人执行）：

  certutil -hashfile 双击运行体检.exe SHA256

两串字符完全一致，就是同一个文件。

5. 报告在哪、怎么发给别人
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
点「生成报告（网页版＋文字版）」后，在程序旁边会出现一个
「体检报告」文件夹，里面两个文件：

  体检报告-日期时间.html   双击可以看，排版清楚
  体检结果-日期时间.txt    纯文字，适合直接复制粘贴发给帮忙的人

如果那个文件夹不允许写入（放在 U 盘、 Program Files 里），
程序会自动改放到系统临时文件夹，并在界面上明说放在哪。

想更快：直接点「复制结果，发给帮我的人」，粘贴到微信/QQ 就行。

★ 隐私：所有报告会先过一道脱敏处理，自动替换掉本机姓名、电脑名、
  IP 地址、网卡地址、用户目录、SID、以及看起来像密码/令牌的内容。
  界面底部会显示「本次已自动隐藏 N 处个人信息」，为 0 时才说明真的没找到。
  但请注意：红黄绿的文字里可能包含你装了哪些软件。发给陌生人前自己看一眼。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. 「用管理员身份重新体检」是什么时候点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
普通权限已经能完成大部分检查。只有当某一行写着「这一项用普通权限看不全」
时才点它，Windows 会弹一次确认框。
点了以后会打开一个新窗口，标题栏会写着「管理员权限」，老窗口自动关闭；
如果你在新弹窗里点「否」，当前窗口不会退出，体检照常在普通权限下进行。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. 报告说有问题，我该先做什么
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 先备份重要文件（复制到 U 盘或网盘）。任何维修动作之前都做这一步。
  2. 按报告里那条红项下的步骤做，一次只做一项。
  3. 做完点「重新体检」，看那条有没有变绿。
  4. 报告里出现的命令行都是"只查看、不改动"的官方命令；
     地址也只是让你自己核对后打开，程序不会自己去访问。
  5. 反复出现同一个红项、而自己不敢动手时，把 txt 报告原样发给售后或
     懂电脑的朋友，比描述"电脑老重启"有用得多。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. 「开机自启动」为什么不算病毒
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
本工具只对明确写在「故障规则库.json」黑名单里的项目打红标。
Steam、微信、声卡驱动、办公软件这一类正常软件，哪怕没有微软签名，
也不会被打红标——它们本来就该在开机时等着你用。

规则库是纯文本，你可以自己看、自己改（改错了程序会自动退回内置规则，
并在报告里说明）。加条目的方法写在 json 文件里：启动项名字、exe 文件名
要完全一样才算；安装路径按「整段目录名」来认，不限盘符、不限深浅，
但必须写到具体产品目录。模糊关键词一律不认，就是为了避免冤枉正常软件。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. 打不开 / 报错 / 窗口不见了
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 双击没反应：先看是不是被杀毒软件静默隔离了
    （Defender → 保护历史记录）。找回后按第 3 节 C 手动放行。
  · 窗口一闪而过：程序会把这个原因写在
    「体检报告\local_crash.log」。这个文件也过了脱敏，不用截图，
    但里面可能带本机文件夹路径，先发给你信任的人，别贴到公开场合。
  · 体检跑到一半没动：等 30 秒；老机器读事件记录确实会慢一些。
  · 想彻底卸载：整个文件夹删掉。它没有注册服务、没有开机驻留、
    没有后台进程，也不会自己写回任何地方。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. 这套东西的边界（别指望它的事）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 它不查毒。可疑文件请交给杀毒软件。
  · 它不修东西，只报读到的情况和给出人话建议。
  · 绿色不等于电脑绝对健康：事件记录本身会漏，也有的故障只在高负载时出现。
  · 它读不到"别人电脑上的问题"，比如路由器、宽带、学校/公司内网策略。
  · 需要看全部检查项时才有管理员权限的用途，其余功能一律不需要提权。
