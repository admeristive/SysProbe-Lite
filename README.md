# 系统简易体检仪 SysProbe-Lite

给电脑小白做的一键体检。双击就用，全程离线，只读取本机信息，不修改任何东西。

它不修电脑，只负责告诉你：现在这台机器上哪些地方有记录、哪些地方是正常的、下一步该点哪里。

---

## 为什么做这个程序

身边很多人一遇到"电脑蓝屏了""游戏闪退了""是不是中病毒了"，第一反应是下载一个"全能优化大师"。
那些软件会联网、会改设置、会把 Steam 和声卡驱动报成病毒，然后吓你一跳。

SysProbe-Lite 反过来：**只读、不联网、不猜、不吓**。取不到的数据就写"没取到"，绝不用"可能有问题"糊弄人。

---

## 能查什么

普通权限下点一次按钮，本机实测 0.5 秒完成采集（12 项检查），报告里给出十几条结论：

| 检查 | 说的是什么 |
| --- | --- |
| 意外关机 | 最近 30 天有没有蓝屏、有没有说不清的突然断电 |
| 软件闪退 | 哪个软件在反复崩溃（只看两次以上的） |
| 显卡与驱动 | 装了几块显卡、驱动版本、有没有互相冲突 |
| 画面卡死恢复 | 游戏画面突然冻住一两秒再回来，有没有发生过 |
| 常用运行库 | 缺哪个 DLL；只有真出过问题才提，否则不下判断 |
| 代理残留 | 卸载加速器之后留下的那个不再使用的代理地址 |
| hosts 文件 | 有没有被流氓软件改过 |
| 关键服务 | 声音、网络相关的服务有没有被禁用 |
| USB 省电 | 只告诉你去哪儿看，不替你改 |
| 磁盘空间 | 系统盘还剩多少 |
| 开机自启动 | 完整清单 + 只对黑名单里的东西提示 |
| 电池 | 当前电量、损耗率 |

拿不准的项目会老老实实写在"本次没有下判断的项"里，不会伪装成结论。

## 四件绝对不做的事

1. **不联网。** 代码里没有 `requests`、`urllib`、`socket`，一个网络模块都不 import；HTML 报告的样式和图标 100% 内联写死，没有 CDN、没有外链、没有脚本。发布前用静态闸口（`tools/check_no_network.py`）逐文件检查，闸口自带自检，会先证明"规则真的会开火"再宣布通过。
2. **不改系统。** 不写注册表、不删除文件、不结束进程、不修复任何东西。所有可能造成影响的建议都只写"你自己怎么点"，做完还是不做由你决定。
3. **不动杀毒软件。** 不会自动把自己加进 Windows Defender 或任何杀软的白名单。需要加白名单时，说明书只写手工路径，并明确写着"本程序不会替你做这一步"。
4. **不乱打红标。** Steam、微信、声卡驱动、WPS 这类正常第三方软件，哪怕没有微软签名，也不会被标红。黑名单只做**整值/整段匹配**：启动项名字完全一样、exe 文件名完全一样、或者路径里出现一整段目录名（不限盘符、不限深浅，`\2345Soft\` 在 D 盘深层一样认得出来）。写模糊关键词（比如 `update`、`helper`）会把一堆正常软件全点成毒，而把目录规则写成厂商根目录（比如 `\Kingsoft\`）会把同一家公司的正常办公软件也点成毒——这两种都拒绝：规则必须落到具体产品目录。

## 使用教程

### 拿到程序之后

1. 解压到一个**固定文件夹**（别在压缩包里直接双击运行），比如 `D:\体检仪\`。
2. 双击 `双击运行体检.exe`。第一次可能弹出"Windows 已保护你的电脑"，点 **更多信息** → **仍要运行**。
3. 点蓝色的 **开始体检**。
4. 想看结果就点 **生成报告（网页版＋文字版）**，同级会多出一个 `体检报告` 文件夹；要发给别人就点 **复制结果，发给帮我的人**，把那段文字直接粘过去。

### 确认你拿到的文件没被动过

在程序所在文件夹的地址栏输入 `cmd` 回车，执行：

```
certutil -hashfile 双击运行体检.exe SHA256
```

把出来的 64 位字符串和 `必须看的使用说明.txt` 里"本版 exe 的 SHA256"那一行对一下，一模一样就是同一个文件。

### 什么时候需要管理员权限

只有两种情况：**服务到底在不在运行**、**更深层的系统错误记录**。
点底部 **用管理员身份重新体检**，会弹出系统的授权窗口：

- 点 **否**：原窗口照常继续跑，不会闪退，那一项就留空——程序宁可留空也不猜。
- 点 **是**：新的管理员窗口打开（标题栏写着"管理员权限"），旧的普通窗口自动关闭。

### 杀毒软件拦了怎么办

先看 `必须看的使用说明.txt` 第 3 节。大意是：在 Defender 的"保护历史记录"里选"允许"，或者手工添加文件夹白名单。**这一步必须你自己点，程序不会代你做，也没有代做的能力。**

## 打包成 exe

```
py -3 tools/build.py
```

产物在 `dist\双击运行体检\`，根目录严格只有 3 个文件 + 1 个目录：

```
双击运行体检.exe
故障规则库.json
必须看的使用说明.txt
_internal\
```

`tools/build.py` 会自己算 exe 的 SHA256 并**回填**进 `必须看的使用说明.txt`，然后核对发布目录结构、多一个少一个都算失败。打包用 PyInstaller **onedir**（`--contents-directory="_internal"`），**不使用 onefile**——onefile 会把所有东西解压到临时目录，杀软最容易把它当可疑程序。

源码运行：

```
py -3 sysprobe/app.py            # 起界面
py -3 sysprobe/app.py --no-gui   # 不开窗口跑一遍，用于验证
py -3 sysprobe/app.py --gui-check  # 离屏起一次真窗口，把验收结果写到文件
```

验证链：

```
py -3 selftest.py                 # 探针 + 脱敏回归
py -3 tools/rules_check.py        # 规则库能不能读、会不会冤枉正常软件
py -3 tools/check_no_network.py   # 零外联与零写操作闸口（带自检）
py -3 tools/gui_smoke.py          # 真实窗口冒烟
```

## 已知限制（诚实版）

- **不是维修手册。** 它读的是本机的记录，读不到就写"没取到"。硬件时好时坏的间歇性故障，它可能全程显示正常。
- **真正的严重硬件故障常常来不及写日志。** 直接黑屏死机的情况，"没有记录"不等于"没有问题"。
- **普通权限看不到全部。** 未授权时有 2 项留空，这是设计，不是偷懒。
- **换不了结论。** 它不会重启服务、不会补 DLL、不会清hosts——这些动作都会改你的电脑，需要你自己在场。
- **异常不弹窗。** 程序内部出错时不闪退、不弹错误框，而是安静地追加写进 `体检报告\local_crash.log`。**要注意：这个文件里的错误记录没有过脱敏**（堆栈里会带本机路径），所以别把整份日志直接发到公开场合，先发给你信任的那个人，或只转述其中一句话。

## 技术栈

Python 3.11+ · PySide6 · PyInstaller（onedir）· Windows 原生只读采集（`wevtutil.exe`、`winreg`、`ctypes` 系统 API、直接文件读取）。
没有 C#，没有 WPF，没有 pywin32，没有 wmic，没有任何需要联网安装的组件。

规则库 `故障规则库.json` 可以手改，改坏了程序会自动退回内置默认值并在报告里提示规则库不可用。
